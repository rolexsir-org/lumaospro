# Onboarding screen renderings

`01-welcome.png` … `07-complete.png` are **static design renderings**, generated from the app's
own string resources and the layout values in `onboarding/OnboardingScreens.kt`. They are not
device screenshots: this workspace has no emulator, Android SDK or Gradle, so nothing here was
rendered by Android.

Use them to review copy, order and hierarchy. For real appearance, TalkBack behaviour, insets
and text scaling, run section D10c of `docs/QA_CHECKLIST.md` on a device.

`index.html` is the gallery view.
